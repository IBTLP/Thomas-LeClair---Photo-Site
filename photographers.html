For photographers

I’m sharing a small set of tools I’ve built for car shows — because this craft is part of what I love, and the more we raise the bar, the better it gets for everyone.

Your browser may ask to allow multiple downloads. If it does, choose Allow. Prefer one ZIP instead? I’ll add a single-pack download shortly.
Fast workflow: Apply preset → adjust Exposure → pull Highlights down if paint/chrome is hot → lift Shadows a touch if wheels/grille are dark.
Install: Lightroom → Presets panel → "..." menu → Import Presets → select the files (or place them into a folder and import as a group).
